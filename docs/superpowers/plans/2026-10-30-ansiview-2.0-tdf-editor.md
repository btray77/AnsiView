# AnsiView 2.0 TheDraw Font Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) with superpowers:test-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A real TheDraw font (.TDF) editor (fonts plan stretch goal 6, STUDIO-CHECKLIST row "TDF font import, preview, insert, manage collection"): create a font of any of the three TDF types, open an existing .TDF collection (pick, add, delete, rename, reorder its fonts), edit glyphs with the ANSI editor's own canvas and tools on a glyph sized canvas, see all 94 characters in a grid, copy, paste and clear glyphs (also from another installed font), preview typed text live with the Text to ASCII renderer, save and save as .TDF (re-opens identically, loads in Font Manager and Text to ASCII), unsaved changes prompt, undo and redo. Entry points: Tools > TDF Font Editor... and Font Manager > Edit Font....

**Architecture:** Pure logic in AnsiCore with Swift Testing tests, in one new file `TDFFontEditor.swift`:
- `TDFLimits`: the specification's limits (width 1 to 30, height 1 to 12, spacing 0 to 40, name 12 CP437 characters).
- `TDFOutlineCode`: the outline placeholder codes (A to R, `@`) with plain English roles, for the code palette.
- `TDFGlyphCanvas`: glyph to `EditCanvas` and back for each font type (lossless for glyphs that are not edited).
- `TDFStorage`: what a glyph becomes when written (`TDFFile.write` then parse), with the cells a TDF file cannot hold fixed or reported (fonts plan deferred minor M9).
- `TDFGlyphConvert`: a glyph copied between fonts of different types.
- `TDFFontEditorModel`: the open collection, selection, every font and glyph command (one undo step each, Foundation `UndoManager`), the glyph editing session (canvas edits become one "Edit Glyph" undo step), the glyph clipboard format, modified state, `fileData()` and `open(data:)`.

The app adds `App/TDFFontEditor.swift`: the window (font list, glyph grid, an embedded `EditorViewController` for the glyph, glyph size and outline code controls, the 19 outline style strip, the live preview, Save, Save As, Open, Install). Shared files get minimal hunks: one menu line in `App/EditorToolCommands.swift`, an Edit Font button in `App/FontManager.swift`, and `applicationShouldTerminate` asking font editor windows too (`App/AnsiViewApp.swift`).

**Tech Stack:** Swift 5 mode, Swift Testing, AppKit, XcodeGen.

## Research (measured on the scratchpad corpus, read only)

`survey.py` over Roy/SAC's collection (1,198 files in `THEDRAWFONTS`): 3,711 fonts (3,541 colour, 163 block, 7 outline), 234,473 glyphs, widest stored width 30, tallest height 12, at most 12 rows; 11,502 glyphs (4.9%) have rows of different lengths, the other 95% store every row at full width; 667,118 rows end with a stored space; 5,539 empty rows; 1,159 rows use 0xFF; spacing values 0 (7 fonts), 1 (825), 2 (2,875), 3 (3), 4 (1).

Roy/SAC's specification (fetched 2026-10-30, https://www.roysac.com/blog/?p=713): "Max Width of Character ( 1 <= W <= 30 (1Eh) )", "Max Height of Character ( 1<= H <= 12 (0Ch) )" ("not reliable"), "Letter Spacing ... range 0-40", font name "max. is 12 characters"; outline codes: `@` "Filler for all leading spaces", `&` "Descender mark", `O` "Hard space for all spaces inside a character", E to L the outer and inner corners (E upper left outer, F upper right outer, G and H inner corners, I and J lower inner, K and L lower outer); A to D and M, N are unreadable on the page (the style table shows A, B horizontal edges, C, D vertical edges, M, N the joints).

## Rulings

1. **Limits.** New and resized glyphs are 1 to 30 columns and 1 to 12 rows; spacing 0 to 40; names 1 to 12 CP437 characters (others refused with a message). Opened glyphs larger than that are shown whole and kept as they are until resized. Cost if wrong: a font made for a tool that allows bigger glyphs cannot be drawn bigger here.
2. **Glyph canvas.** A glyph is edited on an `EditCanvas` of its width (widest row) by its row count. Block and outline cells show their codes in light grey on black (outline placeholders A to R in light cyan, `@` in dark grey, so the shape stands out); colours drawn on them are not stored (block and outline fonts take the user's colours when used). Colour cells show their attribute: foreground low nibble, background bits 4 to 6, and the blink bit as a bright background (the canvas has iCE colours on), so every attribute byte maps to one canvas cell and back. Colours that are not VGA (a pasted image) become the nearest VGA colour. Cost if wrong: an artist who wants to see blinking in the editor sees a bright background instead.
3. **Unedited glyphs stay byte exact.** A glyph is written back from the canvas only when the canvas differs from the one made from the glyph. When it is written, each row keeps its original length if the cells past that length are still blank (space, light grey on black), otherwise it is the full canvas width; new rows are full width (what 95% of collection glyphs do). Width and height bytes are recomputed from the rows for edited glyphs. Rows below the baseline (descender, `&`) keep their flags by row index; the "Rows below baseline" control sets the last N rows. Cost if wrong: an edited ragged glyph gains trailing spaces (invisible with a black background).
4. **What a file cannot hold (fonts plan M9).** Before saving, each glyph is normalized: code 0 and 13 cells become spaces (they end a glyph or a row), a drawn `&` at the end of a row in a block or outline font gets a space after it (so it is not read as the descender mark; looks the same), a colour `&` with attribute 0x00 (black on black, invisible) becomes a space with attribute 0x00, a colour `&` with attribute 0x0D at a row end cannot be stored: it is reported and becomes the descender mark. The save reports every change it made; the model then holds exactly what the file holds, so re-opening gives the same fonts. Cost if wrong: a character silently changes on save (reported, so not silent).
5. **Collections.** A file holds 1 or more fonts (a file with none is refused by the reader, so the last font cannot be deleted). Add (name, type, spacing, empty), duplicate, delete, rename, move up and down. Font type is chosen at creation and not changed later (converting outline to colour is not meaningful).
6. **Copying glyphs between types.** Colour to block or outline drops the attributes; block or outline to colour uses attribute 0x07 (light grey on black); outline to block or colour turns the placeholders into the characters of outline style 1 (`@` and spaces become spaces), so the shape survives; block or colour to outline copies the codes (letters A to R then act as placeholders). The glyph clipboard is a one font TDF file in the pasteboard type `com.traynham.ansiview.tdfglyph`, with the glyph drawn as text beside it. Cost if wrong: a pasted glyph looks different from its source.
7. **Undo.** Font and glyph commands (add, delete, rename, move, spacing, clear, paste, copy from font, resize glyph, descender rows) are one undo step each in the model's undo manager. Drawing on the glyph canvas uses the canvas editor's own undo while that glyph is open; when another glyph is chosen the whole session becomes one "Edit Glyph X" step in the model (so Undo in the grid takes the glyph back). Cost if wrong: two undo histories (canvas and font) where one might be expected.
8. **Saving.** Save writes the file it came from (or asks, Save As). A file saved into AnsiView's font folder (or a font opened from Font Manager) makes the library reload, so Font Manager and Text to ASCII show the change at once; Install copies a saved file into the font folder with the existing import. Bundled AnsiView fonts open as an untitled copy (Save As). FIGlet fonts are not TDF and are not offered. Cost if wrong: editing an imported font changes the user's copy in AnsiView's folder in place (that is what Edit means; the original imported file elsewhere is untouched).
9. **Preview.** The sample text renders with `TextArt.render` (the Text to ASCII renderer) after every change, with the outline style chosen in the preview, and for outline fonts the open glyph is drawn in all 19 styles. Cost if wrong: none (display only).
