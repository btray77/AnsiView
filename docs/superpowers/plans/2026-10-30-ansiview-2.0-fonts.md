# AnsiView 2.0 Text Art Fonts (TheDraw .TDF and FIGlet .flf) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) with superpowers:test-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Owner brief section 1 "Font support" (STUDIO-CHECKLIST rows "TDF font import, preview, insert, manage collection" and "Other font formats (FIGlet .flf)"): import and use classic TheDraw Font (.TDF) files, show previews, insert large text with installed fonts in the editor, offer sizes and styles (outline styles, colours, spacing, FIGlet layouts), manage a font collection, keep the fonts' own colours and characters, and cover the other historical format that matters (FIGlet).

**Architecture:** Pure logic in AnsiCore, each with Swift Testing tests:
- `TheDrawFont.swift`: `TDFFont`, `TDFGlyph`, `TDFFile.parse` (all three types, many fonts per file, caps, never traps), `TDFFile.write`, the 19 outline styles.
- `FIGletFont.swift`: `FIGletFont.parse`, layout modes, the six controlled smushing rules, universal smushing, fitting.
- `TextArt.swift`: `TextArtFont` (either kind), `TextArtOptions`, `TextArt.render` to a `CanvasRegion` (the editor's floating paste input), missing glyph fallback, line wrapping.
- `OriginalFonts.swift`: the bundled original fonts, generated by code from a pixel alphabet drawn for AnsiView.
- `FontLibrary.swift`: installed fonts (bundled plus imported files in the app container), favourites, search, import of files, folders and ZIP packs, remove.
- `FontHelp.swift`: hint and (?) texts, so they are tested for wording rules.

The app adds `App/FontManager.swift` (Font Manager window) and `App/TextToASCII.swift` (the Text to ASCII window with its gallery and detail pane, plus an `EditorCanvasView` extension with the menu actions). `App/EditorToolCommands.swift` gains three menu lines (Text Art..., Text to ASCII..., Font Manager...); `App/AnsiViewApp.swift` gains one line for the Window menu item. `Tool/main.swift` gains `--font` and `--list-fonts`.

**Tech Stack:** Swift 5 mode, Swift Testing, AppKit, XcodeGen.

## Format research (sources)

- TDF: Roy/SAC, "TheDraw Fonts File (.TDF) Specifications", https://www.roysac.com/blog/?p=713 (reverse engineered; the author says so). tdfiglet (tat3r, https://github.com/tat3r/tdfiglet, `tdfiglet.c` `loadfont`, `readchar`): fixed offsets 24 (name length), 25 (name), 41 (type), 42 (spacing), 43 (block size), 45 (offset table), 233 (first glyph data). retrofont 0.2.2 (Markus Krueger, MIT or Apache 2.0, crates.io, `src/tdf.rs`, `src/glyph.rs`): multi font bundles, and the outline style table "copied from TheDraw (19 styles, 17 characters each)".
- FIGlet: "The FIGfont Version 2 FIGfont and FIGdriver Standard" (Cowan and Burton, 1996 to 1997; in the figlet distribution as `figfont.txt`), and figlet 2.2.5's own reference outputs (`tests/res004.txt` default smushing, `res009.txt` kerning, `res010.txt` full width, `res011.txt` overlap), used as test expectations.

File layout used (offsets from the start of the file for the first font):

| Offset | Size | Field |
| --- | --- | --- |
| 0 | 1 | 0x13 (length of the signature) |
| 1 | 18 | `TheDraw FONTS file` |
| 19 | 1 | 0x1A |
| per font +0 | 4 | 0x55 0xAA 0x00 0xFF |
| +4 | 1 | name length (real files write 12 and pad with NUL) |
| +5 | 12 | name |
| +17 | 4 | reserved, zero |
| +21 | 1 | type: 0 outline, 1 block, 2 colour |
| +22 | 1 | letter spacing |
| +23 | 2 | glyph block size, little endian |
| +25 | 188 | 94 little endian offsets into the block for `!` (33) to `~` (126); 0xFFFF is undefined |
| +213 | block size | glyphs: width byte, height byte, cells, CR (0x0D) ends a row, NUL ends the glyph |

Cells: outline and block fonts use one byte per cell; colour fonts use a character byte and an attribute byte (low nibble foreground, bits 4 to 6 background, bit 7 blink or, with iCE, a bright background). Outline cells are letters `A` to `R` that the outline style turns into box characters, `@` (a leading blank), `O` (a blank inside the letter) or a literal byte.

Measured on Roy/SAC's TheDraw font collection (1,242 .TDF files, scratchpad only; `survey.py`, `amp.py`): 3,711 fonts (3,541 colour, 163 block, 7 outline), 556 files hold more than one font, the next font starts right after the previous block (some files pad with NUL), one file ends with a SAUCE record, 234,473 glyphs, widest row 30, tallest glyph 12 rows, 130 glyphs have more rows than their height byte. `&` before a CR or NUL: 67 times in colour fonts, 38 in outline, 64 in block fonts; `&` followed by an attribute (a drawn `&`): 40 times in colour fonts (DOLCEX.TDF), and 8 times mid row in block fonts.

## Rulings

1. **Signature.** A file is TDF when its first 20 bytes are `\x13TheDraw FONTS file\x1A`. Anything else is refused with a message. Cost if wrong: a damaged signature that TheDraw itself accepted is refused.
2. **Fonts in a file.** After a font's block, NUL bytes are skipped; the next font must start with 0x55 0xAA 0x00 0xFF. Anything else (a SAUCE record, junk, the end) ends the list, keeping the fonts already read. A truncated font (header or block past the end) is dropped with a warning; if no font was read the file is refused. Caps: 16 MB per file, 2,048 fonts per file. Cost if wrong: a font after junk in a damaged file is not listed.
3. **Name.** The name length byte is trusted only up to 12, the name stops at the first NUL and is read as CP437; the writer always writes length 12 and NUL padding, as TheDraw files in the collection do. Cost if wrong: none seen.
4. **Spacing** is the stored byte used as is (tdfiglet and retrofont do the same; Roy/SAC's note "stored as 0x01 to 0x29" is read as the range of typical values, since fonts with spacing 1 and 2 both render with the gaps their previews show). The Text Art panel can override it (0 to 40). Cost if wrong: one column more or less between letters by default.
5. **Glyph decoding.** Offsets at or past the block size, or glyphs that run off the block, are undefined glyphs (no trap). Rows stop at CR, the glyph at NUL or at the block end. Caps: 64 rows and 255 cells per row are kept, the rest ignored. A `&` followed by CR, NUL or the block end is the descender mark (Roy/SAC: lines ending in `&` are descender lines that the height byte does not count); it is not drawn and is remembered as a flag on the row. Any other `&` is a drawn character (with its attribute in colour fonts). The width and height bytes are kept for writing but rendering uses the rows. Cost if wrong: a font with `&` meant as a mark mid row draws an `&`.
6. **Writer.** Writes the signature, every font (header as in ruling 3, type, spacing, block size, offsets) and its glyphs (width, height, cells, `&` at the end of descender rows, CR between rows, NUL), then nothing after the last block (as the collection's single font files). Identical glyph bytes share one offset. A font whose block would exceed 65,535 bytes is refused with an error. `parse(write(fonts)) == fonts` for every parsed font (tested on our fonts, fuzzed fonts and, in the scratchpad, on all 3,711 collection fonts).
7. **Outline styles.** The 19 TheDraw styles (retrofont's table, converted back to CP437 codes) map letters `A` to `Q`: A top edge, B bottom edge, C left edge, D right edge, E to L the corners, M and N the tees, O, P, Q blanks. `R` and other letters past Q draw a space (retrofont's `transform_outline`). `@` is a gap (nothing drawn), `O` a space in the current colours. Outline and block fonts draw in the current foreground and background. Styles 16 to 18 are the half and full block styles. Cost if wrong: a style's character differs from TheDraw's.
8. **Colour fonts** keep each cell's character and attribute: foreground `attr & 15`, background `(attr >> 4) & 7`, blink `attr & 0x80`. The floating paste converts blink to a bright background on an iCE canvas (`EditCanvas.cell(_:iceColors:)`), which is how such fonts were drawn on iCE art; the preview does the same for the canvas's iCE setting. The current colours are not used. Cost if wrong: none; this is what the bytes mean.
9. **Gaps and transparency.** Cells a glyph does not cover (short rows, `@`, spacing, the space between words, missing glyphs, rows below a short glyph) become a space in the current colours. With Transparent (the editor's existing transparent paste) they leave the art underneath; so do spaces drawn by the font (TheDraw has no way to say which spaces are opaque, and AnsiView has no opaque blank character). Cost if wrong: hollow letters over existing art show the art inside when Transparent is on.
10. **Missing glyphs and spaces.** A missing lower case letter uses its upper case glyph and the other way round; any other missing character (and characters outside `!` to `~`) becomes a gap as wide as a space. A TDF font has no space glyph: a space is as wide as half the average width of the font's defined glyphs, rounded up, at least 1. Cost if wrong: words sit closer or further apart than in TheDraw; the spacing override does not change it.
11. **Layout.** Letters are top aligned; a line is as tall as its tallest glyph (descender rows included). Text with line breaks makes several lines, one empty row between them. Optional wrapping to a width (the canvas width in the editor): words move to the next line when they do not fit; a word wider than the width is cut between letters. The result is clipped to 1,000 columns and 1,500 rows (the canvas limits). Cost if wrong: one blank row between lines.
12. **FIGlet parsing.** Header `flf2a` plus the hardblank character, height, baseline, max length, old layout, comment lines, optional print direction, full layout and code tag count. After the comments: characters 32 to 126, then the seven Deutsch characters (196 214 220 228 246 252 223), then code tagged characters (decimal, `0x` hex or `0` octal, negative codes skipped) until the end. Each line loses its CR/LF, then the end mark (its last character) and every repeat of it at the end. Missing lines or a short file end the character list (fonts may stop early). Caps: 4 MB, height 1 to 64, 4,096 characters. TOIlet `tlf2a` files are read the same way (UTF-8). Cost if wrong: an odd font loses its last characters.
13. **FIGlet layout.** With a full layout value, bits 0 to 5 are the horizontal smushing rules, 64 is fitting and 128 smushing; without it, old layout -1 is full width, 0 fitting and a positive value smushing with rules `old & 63`. Text Art offers Font default, Full width, Fitting, Smushing (font rules) and Universal smushing (figlet `-o`). The algorithm is figlet 2.2.5's `smushamt` and `smushem` (including the rule that characters narrower than 2 columns do not smush). Right to left print direction is ignored (left to right only). Output is in the current colours; the hardblank becomes a space; characters map to CP437 where they can and to `?` otherwise. Proof: figlet's own reference outputs (res004, res009, res010, res011) for `<joshk>` in standard.flf, in the scratchpad. Cost if wrong: smushed letters differ from figlet.
14. **Bundled fonts.** Originals generated by `OriginalFonts.swift` from a pixel alphabet drawn for AnsiView (A to Z, 0 to 9, common punctuation): "AV Outline" (type 0, a contour traced around each letter), "AV Block" (type 1, half blocks), "AV Ember" (type 2, colour gradient with a shadow), and "AV Contour" (FIGlet, ASCII contour). Plus the 18 FIGlet 2.2.5 distribution fonts under its New BSD licence (ruling 20, which superseded the first decision not to bundle standard.flf), copied unchanged into `Resources/FIGlet` with `LICENSE-FIGlet.txt`. No TDF font other than ours is bundled (licences unclear). Cost if wrong: the FIGlet fonts would have to be removed from the bundle.
15. **Library.** Imported files are copied to `Application Support/AnsiView/Fonts` in the app container (sandbox safe). The library lists one entry per font (a TDF file with five fonts lists five), with name, kind (TDF outline, block, colour or FIGlet), source file and index. Favourites and the sample text are kept in `library.json` beside the fonts (favourite keys are `file name#index`). Import accepts files (.tdf, .flf, .tlf), folders (searched recursively, 2,000 files at most) and .zip packs (entries with those extensions, using `ZipArchive`). A file whose bytes equal an installed file is skipped; a different file with a taken name gets ` 2`, ` 3`... Files that do not parse are reported and not copied. Remove deletes the file (all its fonts) after a confirmation that names how many fonts go; bundled fonts cannot be removed. Search matches name, file name and kind, case and diacritic insensitive. Cost if wrong: one more prompt.
16. **Font Manager window** (Tools > Font Manager..., also a button in the Text Art panel): search field, Favourites only toggle, table (star, name, kind, file), the selected font's preview of the sample text rendered with AnsiRenderer, sample text field, outline style for outline fonts, Import..., Remove, Reveal in Finder, a (?) on kinds and styles. Multi font files list each font.
17. **Text Art in the editor** (Tools > Text Art...): opens the Text to ASCII window (ruling 20) bound to the editor of the main window, which adds Transparent (the editor's transparent paste) and Insert. Insert calls `beginFloating` on that editor: it floats at the cursor, moves with the mouse and arrows, stamps as one undo step named Paste, Escape cancels; all existing behaviour. The detail pane holds the font, outline style (each style listed with its characters), colours (the editor's by default), spacing (font default or a value), FIGlet layout and wrapping to the canvas width, with a live preview rendered by AnsiRenderer. One window instead of a separate panel: the gallery is the font chooser. Cost if wrong: a small panel would have to be split out again.
18. **CLI.** `ansirender --font <file> [--font-index N] [--outline-style N] [--spacing N] [--fg N] [--bg N] [--layout default|full|fit|smush|universal] [--width N] [--ice] --text "HELLO" [-o out.ans|out.png]` writes ANSI (stdout without `-o`) or a PNG; `ansirender --list-fonts <file>...` prints index, kind, name, spacing and glyph count.
19. **Font editor (stretch).** Not built on this branch; see Deferred.
20. **Text to ASCII window (owner request, 2026-10-30, via the coordinator):** "lets add text to ascii for this similar to these [patorjk.com TAAG, budavariam/asciiart-text]. But better ui/ux than this." Both were looked at for what they do only (type text, pick a FIGlet font, adjust layout, copy); none of their code, text, layout or assets is used. AnsiView's window (Tools > Text to ASCII... and Window > Text to ASCII; the editor's Text Art item opens it with Insert enabled) has one text field and below it a scrolling gallery of the text in every installed font (FIGlet and TDF), each card with name, kind and a favourite star. Cards render on a background queue in visible-first order and a newer keystroke cancels older work, so typing never waits (measured: keystroke to first cards, and the whole gallery, in the harness). Search, Favourites first, Recently used, categories (FIGlet, TDF outline, block, colour, multi line height) and sort by name, height or width. Selecting a card opens the detail pane: a large preview; FIGlet horizontal layout (font default, full width, fitting, smushing, universal) and vertical layout (the same set, FIGlet standard vertical rules 1 to 5); width limit with word wrap; alignment left, centre, right; colours for monochrome fonts (foreground and background, or a gradient across columns or rows); TDF outline style and spacing. Output: Copy as plain text (Unicode or ASCII only), Copy as ANSI, Copy as image (PNG), Copy for code comments (`//`, `#`, `--`, `/* */`, `;` or a box border), Copy for Markdown (fenced block), Save as .txt, .ans or .png, Insert into editor (floating paste), and dragging a card out drops its text. Multi line input renders line by line; characters a font lacks fall back (case swap, then a gap) and the card says which are missing. Keys: arrows move between cards, Return copies the selected card as text, Cmd-F focuses search. Tooltips and (?) hints explain FIGlet layouts and smushing. The first run shows the bundled fonts and an empty state pointing to Import for the user's own collections. Bundled FIGlet fonts: the 18 fonts of the FIGlet 2.2.5 distribution (New BSD, relicensed "as agreed by FIGlet authors" per its CHANGES; figlet is in Debian main), with the licence shipped beside them and in Credits.md; considered and rejected: the figlet.org contributed font database and the large GitHub FIGlet collections (mixed or unknown licences per font), TOIlet fonts (licence not verified), TAAG's font set (mixed licences; TAAG's own assets are not ours). `ansirender --figlet-gallery "TEXT"` prints the text in every bundled font (plus `--font-dir`), each headed by its name. Cost if wrong: one more window to maintain; the gallery can be dropped without touching the editor.
