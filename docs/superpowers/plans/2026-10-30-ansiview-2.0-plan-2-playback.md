# AnsiView 2.0 Plan 2: Playback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver roadmap items 8 to 12: a timeline scrub bar with frame stepping, playback speed remembered per file, optional synthesized modem sounds, terminal style scrolling for tall art during playback, and an optional hold on the final frame.

**Architecture:** Pure logic lives in `Packages/AnsiCore/Sources/AnsiCore/Playback.swift` (timeline and frame math, the per file speed store, the 25 line terminal viewport) and `ModemSound.swift` (sample synthesis). `Shared/AnsiPlayer.swift` stays the one player for the app and Quick Look and only wires these types to AppKit views. Audio output (AVAudioEngine) lives in the app target only, behind a small hook on the player, so the Quick Look extension never makes sound.

**Tech Stack:** Swift 5 mode on the Swift 6.3 toolchain, Swift Testing, CryptoKit (SHA-256 file identity), AVFoundation (`AVAudioEngine`, `AVAudioPlayerNode`), AppKit, SwiftUI commands, XcodeGen.

**Spec:** `docs/ROADMAP-2.0.md` (items 8 to 12) plus the coordinator's notes for plan 2.

## Rulings

1. **What a frame is (item 8).** The corpus animations clear the screen once and then draw with cursor moves (measured: every one of the 15 has exactly one `ESC[2J`), so clears cannot split frames. A frame is one export frame: 1/15 s of the stream at the default 2400 baud (16 bytes), with slices that change nothing on screen merged into the next. It does not depend on the chosen speed, so the step size and the timeline stay put when the speed changes. Cost if wrong: steps feel too fine or too coarse; one constant (`PlaybackTimeline.bytesPerFrame`) changes.
2. **Scrubbing pauses (item 8).** Dragging the bar or stepping pauses playback at that point; Space resumes from there. Cost if wrong: one line to resume after mouse up.
3. **File identity (item 9).** The key is the SHA-256 of the file's bytes (first 16 hex digits). The app's `FileDocument` gets bytes, not a URL, Quick Look gets a URL that differs for the same file, and a content hash survives renames and moves. Two identical copies share one speed. The store keeps the 500 most recently set files. Cost if wrong: a moved file forgets nothing, an edited file forgets its speed.
4. **Changing the speed (item 9).** A menu speed change applies to the focused window's file, is remembered for that file, and also becomes the global speed, which every file without a remembered speed uses. Quick Look reads remembered speeds but never writes them.
5. **Modem sounds (item 10).** Off by default (Playback > Modem Sounds). When on, starting a playback from the beginning plays a dial tone, seven DTMF digits, a ring back, a 2100 Hz answer tone and a short scrambled training burst (about 6 s in all), and the art starts drawing when it ends, as after CONNECT. While bytes flow a quiet noise loop plays; it stops on pause, skip, hold and finish. A click during the handshake skips to the end like any click during playback. Quick Look is always silent: a preview making noise when you press space in Finder would be hostile.
6. **Terminal scrolling (item 11).** For art taller than 25 rows, while playback is in progress (playing, paused, scrubbed or held) the player shows a 25 row window of the canvas that follows the cursor with the least motion that keeps it visible (a cursor below the window puts it on the bottom line, above the window on the top line), scaled to fit like any 25 line screen. When playback finishes it shows the whole art (fit or scroller as before). Rendering 25 rows instead of the whole canvas also makes each tick cheaper. Rejected: scrolling the existing width fitted canvas, because tall art that fits the window would stay tiny and nothing would look like a terminal. Cost if wrong: one function (`TerminalViewport.follow`) and the row count used by layout.
7. **Hold (item 12).** Playback > Hold Final Frame (off by default). Off: unchanged (the end of the stream goes straight to the finished view). On: the end of the stream leaves the player showing the last frame exactly as played (for tall art, the 25 line terminal window), with "Click to continue"; a click or Skip to End finishes (whole art, `onFinished` fires); the next click replays as today. For 25 row art the held frame and finished view look the same; the setting matters for tall art and for the plan 3 slideshow, which advances on `onFinished`.
8. **Quick Look.** It shows the same scrub bar (harmless, useful) and honours hold and terminal scrolling; it has no menus, so Left/Right are also handled in the canvas `keyDown`.

## Review Focus

- A file with no stream (BIN, XBin, empty file) must not show the bar, must not crash on step or seek, and must give an empty `frameEnds` (Task 1 test `binaryFileHasNoFrames`).
- Seeking past the end, before zero, or into the middle of an escape sequence must clamp and still draw (Task 1 tests `seekClamps`, `seekInsideEscapeFinishesIt`).
- A corrupt or foreign value in the speed store (wrong type, non numeric, a speed not in `PlaybackSpeed.choices`) must fall back to the global speed (Task 2 test `corruptEntriesAreIgnored`).
- Cursor rows beyond the canvas (cursor moved down past the last drawn row) must not produce an out of range window (Task 3 test `windowPastEndIsPadded`).
- Synthesized samples must stay inside -1...1 so they never clip (Task 5 test `samplesNeverClip`).

### Task 5: Synthesized modem sounds (item 10)

**Files:**
- Create: `Packages/AnsiCore/Sources/AnsiCore/ModemSound.swift`, `Packages/AnsiCore/Tests/AnsiCoreTests/ModemSoundTests.swift`
- Create: `App/ModemSoundPlayer.swift` (AVAudioEngine; app only)
- Modify: `Shared/AnsiPlayer.swift` (`PlaybackSound` hook, connecting state), `App/AnsiViewApp.swift` (toggle; player gets the sound hook), `PlaybackSpeed.modemSoundsKey = "modemSounds"`

**Interfaces:**
- Produces:
  - `public enum ModemSound { static let sampleRate = 22_050.0; static func handshake() -> [Float]; static var handshakeSeconds: Double; static func lineNoise(seconds: Double, seed: UInt64) -> [Float]; static func goertzel(_ samples: ArraySlice<Float>, frequency: Double) -> Double }`. Handshake segments in order: dial tone 350+440 Hz 1.0 s; digits 5,5,5,0,1,9,8 DTMF 0.1 s each with 0.07 s gaps; 0.4 s silence; ring back 440+480 Hz 1.0 s; 0.4 s silence; answer tone 2100 Hz 1.2 s; training burst 1.0 s (band limited noise plus 1200 and 2400 Hz carriers); final 0.2 s fade. Peak amplitude 0.5; line noise peak 0.06.
  - `protocol PlaybackSound: AnyObject { func playbackStateChanged(_ state: PlaybackSoundState) }`, `enum PlaybackSoundState { case connecting, streaming, quiet }`; player `weak var sound: PlaybackSound?` used only when `PlaybackSpeed.modemSounds` is on.
