**Goal:** Rebuild roadmap item 61 (owner request): an image to ANSI importer with a live preview, perceptual colour matching, per cell glyph search, more dithering, pre-processing, presets, an Auto mode that scores methods, an image optimised XBin palette, and easy PNG conversion (Dock, File > Open, drops, batch, CLI).

The app gets `App/ImageImport.swift` (import window, comparison view) and `App/ImageBatch.swift` (batch conversion); `App/AnsiEditor.swift` changes only inside `importImage()`.

**Tech Stack:** Swift 5 mode on the Swift 6.3 toolchain, Swift Testing, AppKit, CoreGraphics / ImageIO, XcodeGen.

## Rulings

1. **Colour matching is OKLab.** Every "nearest colour" uses squared Euclidean distance in OKLab (Bjorn Ottosson 2020 matrices) with a and b weighted 2 (`OKLab.chromaWeight`, chosen in Task 10: weight 1 put cyan and brown specks on grey anti-aliased edges; 2 removed them, line art delta E 2.29 to 2.29, photo 3.98 to 4.47). The score (ruling 8) stays unweighted. sRGB bytes decode to linear light with the exact sRGB curve. Cost if wrong: colours look off; one constant.
2. **Light is mixed in linear RGB.** Area averaging (cells, shade glyphs, 2x2 blur) and error diffusion work in linear light; only the comparison is in OKLab. A shade glyph's colour is the linear mix of fg and bg by coverage (0.25 / 0.5 / 0.75).
3. **Sampling.** The image (after crop, drawn on black, transparency becomes black) is drawn once with CoreGraphics at the method's sample grid: half blocks `columns x 2 rows`, full blocks and shades `columns x rows`, glyph search `columns*4 x rows*8` (each sample is a 2x2 average of the 8x16 font cell). Rows follow plan 6 ruling 13 (aspect correction). Pixel art sampling uses interpolation `.none`.
4. **Pre-processing** runs on the sampled pixels in gamma (sRGB 0 to 1) space, in this order: background removal mask (flood fill from every edge pixel through neighbours within `backgroundTolerance` OKLab distance of the starting edge colour; removed pixels become black), auto levels (luma 0.5 and 99.5 percentiles stretched to 0 and 1, same gain on all channels), brightness (`+ b * 0.5`), contrast (`(v - 0.5) * (1 + c) + 0.5`), saturation (lerp from Rec. 709 luma by `1 + s`), gamma (`v^(1/g)`), sharpen (unsharp mask, 3x3 box, amount 0 to 2). Ranges: brightness, contrast, saturation -1...1 (default 0), gamma 0.2...5 (default 1), sharpen 0...2 (default 0), tolerance 0...0.5 (default 0.08).
5. **Dithering.** `none`, `floydSteinberg` (7,3,5,1 /16), `serpentine` (same, alternate rows right to left, mirrored), `atkinson` (1/8 to six neighbours, 2/8 lost), `sierraLite` (2,1,1 /4), `ordered` (4x4 Bayer, `(b/16 - 0.5) * 0.25 * strength` added in gamma space). Diffused error is multiplied by `ditherStrength` (0...1, default 1). Error diffusion in glyph search is per cell: the cell's mean linear error is spread to neighbour cells with the same kernel.
6. **Glyph search.** Candidates: space, full block, `▀ ▄ ▌ ▐`, `░ ▒ ▓`; with `extendedGlyphs` also `■ (254) ─ (196) │ (179) ┼ (197) / \ _ ═ (205) ║ (186) ∙ (249)`. Each glyph's 8x16 mask from the canvas font is reduced to 4x8 coverage levels (2x2 averages). For each cell and each glyph the sub pixels are grouped by coverage level; error for fg/bg pair = sum over groups of `Σ|p|² - 2 Σp · c + n |c|²` where `c` is the OKLab colour of the linear mix at that level (precomputed per palette: 16 x 16 x 5). Pairs allowed: any fg 0...15, bg 0...15 with iCE, 0...7 without. Minimum error wins; ties keep the earlier glyph (list order above). Truecolor glyph search uses only the binary glyphs (full, `▀ ▄ ▌ ▐`) with fg and bg the OKLab means of their pixels.
7. **Image palette (XBin).** `PaletteOptimizer.palette(_:count: 16)`: median cut in OKLab over at most 32768 samples (fixed stride, deterministic), then 8 Lloyd (k-means) iterations, each colour rounded to the 6 bit VGA DAC (`round(v * 63 / 255)`, read back as `v6 * 255 / 63`, matching `BinaryFormats.sixBitPalette`), sorted by lightness (index 0 darkest). `EditCanvas.palette: [RGB]?` carries it; `ArtWriter` `.xb` writes flag 0x01 and the 48 byte palette and maps cells to palette indexes. `.ans` from such a canvas writes truecolor SGR (existing behaviour for non VGA colours). Cost if wrong: one more file option.
8. **Metric.** `ImageScore.deltaE(rendered:source:)`: both images drawn at the rendered size (8x16 per cell, VGA font, scale 1), box averaged 4x4 in linear light, mean OKLab distance x 100. 4x4 keeps half block structure (2x4 samples per cell) while judging dither and shade patterns by their blend, as the eye does at viewing distance. SSIM on OKLab L over 8x8 blocks of the same reduced images is reported as a cross check. Delta E ranks Auto because the owner's complaint was colour (yellow becoming brown), which SSIM barely sees. Cost if wrong: Auto picks a worse looking method; thumbnails let the user overrule it.
9. **Presets.** Photo: glyph search, VGA, serpentine at 50% (retuned in Task 10: auto levels raised delta E on the test photo from 4.33 to 7.21 and over-saturated the face, so it is off). Logo / flat art: glyph search, VGA, no dither, extended glyphs off. Pixel art: half blocks, VGA, no dither, nearest neighbour sampling, columns = image width (clamped to 1...1000). Line art: glyph search with extended glyphs, no dither, auto levels, contrast 0.3. Auto: runs best character with serpentine 50%, best character without dither, best character with line glyphs, half blocks + Floyd-Steinberg, half blocks + Atkinson, half blocks without dither, and shades + Sierra Lite with the user's width, palette, iCE and adjustments; sorted by delta E; the top 3 are thumbnails. Values may be retuned from the Task 10 measurements (record any change here). Edge to box drawing line art is a stretch goal: not in this plan. A texture penalty for two colour shade patterns (charging k(1-k)|fg-bg|²) was tried at 0.35 and 0.7 and rejected: it turned the test face grey and raised photo delta E from 3.98 to 5.23.
10. **Preview.** `PreviewScheduler` debounces 120 ms, gives each request a generation number, runs work on a serial background queue and drops results whose generation is stale; the converter takes a cancel closure checked once per cell row. Target: preview visible within about 300 ms for 80 columns.
11. **Opening images.** `AnsiDocument.readableContentTypes` gains `.image`; an image document opens the import window and closes its own window. Info.plist adds a `public.image` document type with role Viewer and rank Alternate (AnsiView never becomes the default PNG app). Drops of image files onto art windows, the editor and the import window open the import window. Finder Quick Action: not added (plan 10).
12. **CLI.** `ansirender --from-image <image|dir|->... [--preset auto|photo|logo|pixel|line] [--width N] [--mode glyph|half|full|shade] [--palette vga|truecolor|xbin] [--dither none|fs|serpentine|atkinson|sierra|ordered] [--strength 0-100] [--extended-glyphs] [--ice|--no-ice] [--no-aspect] [--levels] [--brightness N] [--contrast N] [--saturation N] [--gamma N] [--sharpen N] [--remove-background [tolerance]] [--crop x,y,w,h] [-o out|dir]`. One input: `-o` is a file (stdout without it). Several inputs or a directory: `-o` must be a directory, names come from `BatchNaming`, extension `.xb` for the xbin palette else `.ans`. `-` reads stdin. Exit 1 if any input fails, 2 for bad options. Old flags keep working (`--mode half|full|shade`, `--palette vga|truecolor`, `--dither none|fs|ordered`).

## Review Focus

- An image with alpha (logo on transparent background): transparency becomes black and background removal treats it as background (test `transparentLogoBecomesBlack` in Task 2).
- A crop rectangle partly or wholly outside the image, or zero sized: clamped, or ignored when empty (test `cropClampsAndIgnoresEmpty` in Task 2).
- Changing settings faster than renders finish: only the newest result is delivered, never an older one after it (test `staleResultsAreDropped` in Task 8).
- A huge source (for example 8000 x 8000) at 160 columns with glyph search: sampling is at the grid size, not the source size, so memory stays bounded (test `largeImageSamplesAtGridSize` in Task 2).
- A folder for batch conversion containing non images and name clashes (`a.png`, `a.jpg`): non images are reported and skipped, names do not overwrite (test `batchSkipsNonImagesAndAvoidsClashes` in Task 7).
