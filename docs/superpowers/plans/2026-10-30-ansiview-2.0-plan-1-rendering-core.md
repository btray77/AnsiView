# AnsiView 2.0 Plan 1: Rendering Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move rendering into a tested Swift package and deliver roadmap items 1 to 7: real bitmap fonts, Amiga/C64/Atari fonts, 9 pixel mode and aspect, 256 and 24 bit color, UTF-8, binary and BBS code formats, and a CRT look.

**Architecture:** A local Swift package `Packages/AnsiCore` (pure Swift, CoreGraphics/CoreImage only, no AppKit) becomes the single source of parsing, file loading, fonts and rendering for the app, the Quick Look extension, `ansirender`, and later the iOS app. An `ArtFile` loads any supported file into either an ANSI byte stream (played through `AnsiTerminal`) or a finished `AnsiScreen` (binary formats). Cells carry RGB colors, glyphs come from `BitmapFont`, and `AnsiRenderer` draws cells with a font at an integer scale.

**Tech Stack:** Swift 6.3 toolchain in Swift 5 language mode, Swift Package Manager, Swift Testing (`import Testing`), CoreGraphics, CoreText (font rasterizing only), CoreImage (CRT filter), XcodeGen.

**Spec:** `docs/ROADMAP-2.0.md` (items 1 to 7).

## Global Constraints

- macOS 14.0+, universal build; package platforms `.macOS(.v14), .iOS(.v17)`.
- `AnsiCore` imports no AppKit or UIKit.
- No em-dash characters in any file, string or commit message.
- Font files keep their license; each is listed in `Credits.md` with source URL and license. VileR's Oldschool PC Font Pack is CC BY-SA 4.0.
- No Trade Wars or other third party art in the repo; test fixtures are built in code or are original.
- Bump `CURRENT_PROJECT_VERSION` in `project.yml` with each task's commit; set `MARKETING_VERSION: "2.0.0"` in Task 1.
- `./install.sh` must build and the Quick Look preview must still open a `.ans` file at the end of every task.
- Local regression corpus (not committed): `../extracted/TWSUPP/*.ANS`; `ansirender --stats` output for it must keep the same `animated=` and `blink=` column as commit `b875ac2` unless a task says otherwise.

## Review Focus

- Truncated or malformed streams: an `ESC[` at end of file, parameters like `ESC[99999C` or `ESC[999999999m`, and NUL bytes must never crash or allocate unbounded memory; they render what came before. (Task 1)
- Bogus SAUCE: width 0, width 65535, a `COMNT` count larger than the file, and a SAUCE record that is the whole file must fall back to defaults. (Task 2)
- Unknown or misspelled SAUCE font names must fall back to IBM VGA rather than failing. (Task 4)
- Plain CP437 art with high bytes must not be misdetected as UTF-8 (a file of `0xDB 0xDB 0xB0` is CP437). (Task 6)
- Very large files (a 10 MB stream, a 100,000 line ASCII file, a BIN with SAUCE width 1000) must load within the existing 1500 row cap and render without exceeding about 200 MB. (Tasks 6 and 7)
