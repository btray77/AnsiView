# AnsiView 2.0 Editor v2: TheDraw-class Drawing Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) with superpowers:test-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Roadmap item 60 plus the owner brief sections 1 and 7 (STUDIO-CHECKLIST rows marked "editor v2" and "item 60"): the power of TheDraw without its dated interface. Line mode with auto-joining box characters, shape tools, character and colour brushes with a CP437 character picker, flood fill and global replace, insert and overwrite modes, selection move / mirror / rotate / crop with character remapping, layers with a sidecar project file, a tool palette with hints everywhere, grid, zoom and pan, full screen, a retro theme, configurable shortcuts, SAUCE preservation, and measured performance on a 160 x 1500 canvas.

**Architecture:** Pure logic in AnsiCore, each with Swift Testing tests:
- `BoxDrawing.swift`: the four direction connection model (`BoxWeight`, `BoxJoin`), the CP437 table for 0xB3 to 0xDA, `LineStyle`, and `EditCanvas` line drawing, joining and erasing.
- `Shapes.swift`: `ShapeStyle`, rectangles (outline, filled, shadow, title), straight lines, half block ellipses.
- `CanvasTools.swift`: flood fill, global replace, colour swap, character and colour brush, insert / delete of cells, rows and columns.
- `CellTransform.swift`: mirror and rotate tables and region transforms.
- `CharacterPicker.swift`: CP437 names and the favourites / recently used model.
- `Layers.swift`: `CanvasLayer`, compositing, flattening, `ArtProject` (the `.ansiproj` format).
- `SaucePreservation.swift`: what an opened file carries that a save cannot keep, reported to the user.
- `EditorShortcuts.swift`: actions, key combinations, defaults, conflicts, storage.
- `CanvasEditor.swift` gains the commands (each one undo step), layers, insert mode, lift / move / duplicate.

The app adds `App/EditorTools.swift` (tool palette, options bar, hint tracking, grid, retro theme), `App/EditorPanels.swift` (character picker, layers panel, shortcuts preferences) and `App/EditorToolCommands.swift` (one `Commands` block, the Tools menu, added to `AnsiViewApp.swift` with a single line). `App/AnsiEditor.swift` routes mouse and keys through the current tool.

**Tech Stack:** Swift 5 mode on the Swift 6.3 toolchain, Swift Testing, AppKit, SwiftUI commands, XcodeGen.

## Rulings

1. **Connection model.** Each CP437 box character is four weights (up, down, left, right), each `none`, `single` or `double`. The table covers all 40 codes 0xB3 to 0xDA. Mapping a join back to a code picks the exact character when one exists; CP437 has no character for some mixes (for example single up with double down, or a single horizontal meeting a double horizontal), and then the nearest is used: per direction, presence mismatch costs 4 and weight mismatch costs 1; ties prefer keeping the horizontal weights. A join with one direction only (a line end) uses the straight character of that axis. Cost if wrong: one table and one distance function.
2. **Line styles.** `single`, `double`, `singleHDoubleV` (single horizontal, double vertical), `doubleHSingleV`. A horizontal step uses the style's horizontal weight, a vertical step its vertical weight. Drawing a step from cell A to cell B adds A's connection toward B and B's toward A, merges with what the cells already are (existing box characters are read back into joins; any other character counts as empty), and writes the character in the current colours. Erasing removes those two connections; a cell left with no connections becomes a space in the current colours; neighbours are rewritten from their remaining connections. Cost if wrong: line mode.
3. **Line mode input.** Line tool: arrows draw from the cursor (Option-arrow erases); a mouse drag draws a Manhattan path through every cell the mouse passes (horizontal first). One mouse drag is one undo step; each arrow step is one undo step.
4. **Shape styles.** `line(LineStyle)` (box outline built through ruling 2, so overlapping boxes join), `solid` (219), `halfBlock` (top edge 223, bottom 220, left 221, right 222, corners 219), `shade(1...3)` (176, 177, 178). Filled rectangle fills the inside with the brush character (default space in the current background) inside an outline, or the whole rectangle in solid style. Drop shadow (TheDraw style): the two columns right of the box from the second row down and the row under the box from the third column on keep their characters but get foreground dark grey (8) on black. Title: ` Title ` written over the top edge starting two columns in, clipped so the corners stay. Straight line: box styles snap to horizontal or vertical (the longer axis); block styles use Bresenham over cells. Ellipse: midpoint ellipse in half block pixels (cheap, done). Cost if wrong: drawings look different, nothing breaks.
5. **Brushes.** Character brush writes the chosen character with the current colours under the mouse; colour brush sets fg and bg and keeps characters; the half block brush is plan 6's. Right button paints with fg and bg swapped. The character comes from the CP437 picker: a 16 x 16 grid of all 256 codes, hover shows the code (decimal and hex), the Unicode scalar and its Unicode name (`Unicode.Scalar.Properties.name`, with control code names for 0x00 to 0x1F as their CP437 glyph names where Unicode has none), favourites (toggle, kept in defaults) and the 16 most recently used (newest first, no duplicates).
6. **Fill and replace.** Flood fill is 4-connected from the clicked cell, matching neighbours by character, by colour (fg, bg and blink) or by both, and applying the character, the colours or both. It never leaves the canvas and is iterative (no recursion). Global replace: every cell in the selection (or canvas) that matches a cell pattern (character and/or colours) gets the replacement character and/or colours. Fg/bg swap: X key (configurable) swaps the current drawing colours; with iCE off a bright foreground becomes the dark background. Tools > Swap Colours in Selection swaps each cell's fg and bg.
7. **Insert and overwrite.** The Insert key (configurable; Mac keyboards often lack it, so Tools > Insert Mode toggles too, and the Help key counts as Insert) switches modes; the status bar shows INS or OVR. Insert mode typing shifts the rest of the row right (the last cell falls off); Backspace deletes left and shifts the row left; Delete deletes at the cursor and shifts left. Overwrite mode keeps plan 6 behaviour (Backspace moves left and clears, Delete clears). Insert / delete line and column at the cursor (Control-N, Control-Y, Control-Shift-N, Control-Shift-Y, the WordStar keys TheDraw users know).
8. **Selection move (owner request, 2026-10-30).** "Need to be able to move selected area, like pasted or existing." Any selection lifts into a float exactly like a floating paste. In Select mode dragging from inside a selection lifts and moves it; Option-drag duplicates (the original stays). Option-arrow moves a selection one cell, Shift-Option-arrow eight, lifting it first. The vacated cells become a space in the current background on the bottom layer, or transparent on an upper layer; the setting "Leave a copy when moving" keeps them instead. While lifted: Return, Enter or a click outside stamps, Escape puts it back (nothing changed), T toggles transparency. The whole lift, move and stamp is one undo step named Move (or Duplicate); undo restores the original position. After stamping the stamped rectangle stays selected so it can be moved again; a stamped paste is plain cells and moves the same way. The status bar shows a hint while dragging and while lifted; the pointer is the open hand inside a selection. Cost if wrong: one interaction.
9. **Mirror and rotate.** Mirror horizontal swaps every box character's left and right weights (so ┌ becomes ┐, ╟ becomes ╢) plus pairs `▌▐`, `/\`, `<>`, `()`, `[]`, `{}`, `→←` (26/27), `►◄` (16/17), `«»` (174/175), `┤├` through the join model. Mirror vertical swaps up and down plus `▀▄`, `/\`, `↑↓` (24/25), `▲▼` (30/31), `⌠⌡` (244/245). Rotate 180 is both. Rotate 90 clockwise maps joins (up to right, right to down, down to left, left to up) plus `▀▐▄▌` in a cycle, `─│` and `═║` through joins, `/\`, `-|`, arrows in a cycle; it is offered only when the rotated block fits the canvas width (rows grow as needed). Each is one undo step; the selection follows the transformed block. Crop to selection replaces the canvas with the selection (all layers), one undo step.
10. **Layers.** `CanvasLayer` has a name, visibility and an `EditCanvas`. A cell on an upper layer is transparent when it is unset, which means equal to the default blank cell (`AnsiCell()`: space, grey on black, no blink); erasing on an upper layer makes cells transparent. Layer 0 is opaque. The editor draws and saves the composite of visible layers (hidden layers are not saved in `.ans`, `.bin`, `.xb`). Commands: add, delete (not the last), duplicate, move up / down, toggle visibility, rename, merge down, flatten. Layer changes are undo steps. All layers share columns, iCE and SAUCE metadata (resize, iCE and SAUCE edits apply to all). Saving `.ans` / `.bin` / `.xb` always flattens; plain files are byte identical to saving the flattened canvas (test). Cost if wrong: an upper layer cannot hold an opaque default blank; a space in colour 7 on 0 with any other attribute (or a different foreground) is visually identical and opaque.
11. **Project file `.ansiproj`.** JSON (UTF-8, sorted keys): `{"format": "AnsiView project", "version": 1, "columns", "iceColors", "title", "author", "group", "comments", "fontName", "sauceFlags", "sauceTInfo34", "sauceDate" (YYYYMMDD, optional), "activeLayer", "frames": [{"layers": [{"name", "visible", "height", "cells" (base64 of the AVCELLS1 cell encoding), "scalars" ([[x, y, scalar]] for UTF-8 only cells)}]}]}`. Version 1 writes exactly one frame; the frame list is the seam for animation (item 59). Readers reject other formats and newer versions with a message. Tools > Save Project... and Open Project.... Cost if wrong: a format change before 2.0 ships.
12. **SAUCE preservation.** Opening a file for editing keeps title, author, group, comment lines (now read without trimming leading spaces), font name, every flag bit except iCE (which follows the canvas), and TInfo3 / TInfo4 for ANSI and XBin saves. What cannot be kept is reported, never dropped silently: an animation (only the final frame is edited), a SAUCE data type or file type other than what the save writes (for example ANSiMation, ASCII), an embedded XBin font or palette, UTF-8 only characters (`.ans` writes "?"), colours outside the VGA palette (`.bin` / `.xb` write the nearest), trailing data after the end of file marker, and more than 255 comment lines. Edit Art shows the open report once; Save shows the save report and asks to continue. Cost if wrong: one more alert.
13. **Shortcuts.** `EditorAction` lists every keyboard action with its title, hint and default `KeyCombo`. Defaults use Control so they work while typing text: tools Draw ^D, Select ^S, Line ^L, Box ^B, Fill ^F, Text ^T, Brush ^R, Eyedropper ^E; swap colours X (a plain key: outside the Text tool); insert mode Insert; insert / delete line and column (ruling 7); lift selection ^G; mirror ^H / ^V; rotate 180 ^U, rotate 90 ^O; character picker ^P; next line style ^K; grid ^' . Overrides are stored in defaults under `EditorShortcuts` as a dictionary of action raw value to combo string. The preferences pane (Tools > Editor Shortcuts...) lists actions with their keys, records a new key, shows conflicts (two actions with one combo) in red, and resets to defaults. Cost if wrong: different default keys.
14. **Interface.** Tool palette: Draw (half blocks), Select, Line, Box, Fill, Text, Brush, Eyedropper, each with a tooltip; the options bar shows the tool's settings (line style, shape and style, filled, shadow, title, fill match and apply, brush kind and character). The status bar shows the cursor position, size, INS/OVR, the layer, and the hint for the tool or the control under the mouse. Grid overlay toggle; zoom with Cmd + / Cmd -, pinch, and Control-scroll; pan with scroll, space-drag (not in the Text tool) and middle-drag. Full screen (View > Enter Full Screen and the window button). Retro theme (Art > Retro Theme): DOS blue chrome with VGA font labels; native look is the default. Text tool: click places the cursor; typing works in every tool except where a tool key applies.
15. **Performance.** Measured in tests on 160 x 1500: a 200 cell box outline draw and a full canvas flood fill; reported with timings. A refresh after a change re-renders only touched bands (plan 6).
