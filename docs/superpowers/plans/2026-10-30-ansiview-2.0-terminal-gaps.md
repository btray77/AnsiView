# AnsiView 2.0 Terminal Gaps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the terminal compatibility gaps left by the terminal compat plan (flaky transport tests, the EGA 8x14 font, the rest of RIPscrip including .RIP viewing, VT52, inbound sixel and iTerm2 images, platform minors, TLS client certificates, mouse reporting) so AnsiView works with every BBS family still reachable.

**Architecture:** Pure logic in AnsiCore with Swift Testing tests written first: `RIPStrokeFont` (original vector glyphs), `RIPIcon` (BGI image format), `RIPTerminal` gains a file provider, buttons with groups, a drawing budget and queued input; `AnsiScreen.underlay` (a raster drawn under black text backgrounds) lets the shared renderer, the viewer, Quick Look and `ansirender` show RIP files; `SixelDecoder` and `ITerm2Image` decode into bounded `TerminalImage`s that `TerminalEmulator` anchors to cells; VT52 is a `TerminalProfile`. The app supplies the RIP icon folder (security scoped bookmark) and a Keychain identity for TLS.

**Tech Stack:** Swift 5 mode, Swift Testing, CoreGraphics/ImageIO (PNG/JPEG/GIF decode for iTerm2 images), Network.framework (`sec_protocol_options_set_local_identity`), Security.framework (`SecItemCopyMatching` for identities), AppKit, XcodeGen.

**Spec:** coordinator brief of 2026-10-30 (priority list 1 to 8), `docs/BBS-COMPAT.md` section "Terminal" (Coverage, Found along the way), deferred items in `docs/superpowers/plans/2026-10-30-ansiview-2.0-terminal-compat.md`, RIPscrip 1.54 (`RIPscrip154.txt`).

## Review Focus

1. A hostile RIP stream (huge text sizes, thousands of buttons, endless flood fills, 1R recursion) must not freeze the UI: per feed drawing budget with queued input; 1R depth 1; test `ripBudgetDefersWork`, `readSceneDoesNotRecurse`.
2. A hostile sixel or iTerm2 payload (giant raster attributes, endless repeat counts, 2 GB base64) must not grow memory without bound: caps on pixels per image, total image bytes, payload bytes; fuzz tests with seeded random input.
3. RIP icon names with paths (`../x`, `/etc/x`) must never leave the chosen folder: `RIPFileName.sanitize` test.
4. Existing art must render byte identical except IBM EGA files: corpus md5 check.
5. VT52 sequences split across feeds: byte by byte equals whole.

## Rulings

1. Flaky tests: cause measured (cooperative pool starvation of the test task vs. the client's 15 s timeout on a dispatch queue); fix is in tests only (long connect timeout where the timeout is not under test; `eventually` does not count late resumption). No product change.
2. EGA: draw each TTF at its own pixel size (units per em over advance), so 8x14 is drawn at 16 points; any SAUCE "IBM EGA" art changes (intended).
3. RIP 1W writes icons to an in memory store for the session only, never to disk (a BBS cannot write files on the Mac). 1I, 1R, 1F, icon buttons read the session store first, then the user's chosen icon folder.
4. RIP block transfers (9 ESC): Zmodem is already auto detected; for the other protocols the command is parsed and reported (`takeBlockTransfer`) and the app starts its existing receive or send flow when it has one; otherwise a status message.
5. BGI stroke fonts 1 to 10: one original single stroke alphabet, styled per font (triple stroke, slant, double, thick, narrow) and sized from the RIPscrip 1.54 font metric tables (cap height base minus top).
6. Inbound images draw over the text cells they cover and scroll with them; erase display removes them.
7. TLS client certificate: per entry Keychain identity chosen by label (persistent reference stored), used only when the server asks.

## Tasks

### Task 1: Flaky transport tests
- Measure with a temporary print in `eventually` (late `Task.sleep`), reproduce under 10 `yes` loops, fix tests (`testConnectTimeout`, starvation aware `eventually`), 4 runs before and after.

### Task 2: EGA 8x14 rasterization
- Test `egaFullBlockFillsTheCell`: `BitmapFont.named("IBM EGA").pixels(for: 0xDB)` all true; 0xDB of VGA and EGA43 still all true; `BitmapFont.rasterSize(advanceUnits:unitsPerEm:width:)` gives 16 for 1600/800/8. Before and after PNGs of an original EGA SAUCE file.

### Task 3: RIP stroke fonts, icons, scenes, queries, buttons, budget
- `RIPStrokeFont.swift`: `static func strokes(for: UInt8) -> [[(Int, Int)]]`, `metrics(font:size:) -> (top, base, drop)`, `RIPCanvas.text` uses them for font 1 to 10. Tests: font 1 size 4 "H" height equals base minus top from the table; vertical direction rotates.
- `RIPIcon.swift`: `RIPIcon.decode([UInt8]) -> (width, height, pixels)?` and `encode`, spec example bytes `05 00 01 00 0C 14 24 44 20 40 98 C4 00` decode to `00 01 02 04 08 0F / 03 05 08 03 02 01`.
- `RIPFileProvider` protocol (`data(named:)`, `info(named:) -> (size: Int, date: Date)?`), `RIPFileName.sanitize`.
- Commands: 1I, 1W (session store), 1R (depth 1), 1F modes 0 to 4, 1G copy region, 1 ESC query (mode 0, $ variables blank except $DATE$, $TIME$, $X$, $Y$), 9 ESC block mode, button styles (orientation, bevel, chisel, recess, sunken, dropshadow, icon, clipboard, plain, autostamp, underline hotkey, radio and checkbox groups, invertable, selected), hotkeys.
- Budget: `RIPTerminal.drawingBudget` pixel operations per `feed`; extra input queued; `hasPendingWork`; `feed([])` continues.

### Task 4: RIP files in the viewer and Quick Look
- `AnsiScreen.underlay: RasterImage?`, renderer draws it under black backgrounds; `ArtFormat.rip` (extension `rip` or `!|` at the start) builds the screen with `RIPTerminal`; Info.plist UTIs for `.rip` in App and Preview. Tests: rendered pixel from a RIP bar shows its colour; detection.

### Task 5: VT52
- `TerminalEmulation.vt52`, `TerminalProfile.vt52`: ESC A B C D H J K Y r c, ESC F/G graphics, ESC Z reply `ESC / K`, ESC = / > keypad, ESC < leaves for ANSI (VT100), keys send `ESC A` etc. Tests split byte by byte.

### Task 6: Inbound images
- `SixelDecoder` (DCS P1;P2;P2 q ... ST, raster attributes, colour registers HLS and RGB, repeat, caps), `ITerm2Image` (OSC 1337 File=...:base64 BEL/ST, inline=1, width/height in cells, px, %, auto; ImageIO decode; caps), `TerminalEmulator.images` anchored in absolute lines; protocol `images(scrollOffset:) -> [TerminalImage]`. Fuzz tests with seeded random payloads.

### Task 7: Platform minors
- Amiga palette (AmiExpress colours) for the Amiga profile; C128 underline (VDC attribute bit, 0x02 on, 0x82 off) and C128 ESC sequences (ESC Q, ESC @, ESC J/K, ESC P, ESC E/F); Mode 7 VDU 22 mode change (modes 0 to 6 as text grids) and VDU 23 user characters; MouseText glyphs for Apple II (ESC/ Ctrl-[ MouseText on/off of the 80 column firmware); ATASCII inverse key toggle (Atari key on Option-I); Avatar fill restores autowrap and ^L uses the stored attribute.

### Task 8: TLS client certificate
- `BBSEntry.tlsClientIdentity: Data?` (persistent reference) and label; `TCPTransport` sets `sec_protocol_options_set_local_identity`; app picker lists Keychain identities. Test: local `openssl s_server -Verify 1` accepts the client identity.

### Task 9: Mouse reporting and CTerm fonts (if time)
- `CSI ? 1000/1006 h` X10 and SGR mouse reports from clicks; `DCS CTerm:Font:n:<base64> ST` loadable fonts used by `CSI n SP D`.

### Task 10: Docs, review, fixes, cleanup
- BBS-COMPAT Terminal section, STUDIO-CHECKLIST, FONTS; opus review; lsregister cleanup.
