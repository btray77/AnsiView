# AnsiView 2.0 Copy and Paste Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) with superpowers:test-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner asked: "I want a copy paste feature to work with that select feature." Copy from an editor or viewer selection puts cells, text, ANSI and a picture on the pasteboard in one write; Edit > Copy As picks one; Paste in the editor floats the block until it is placed; pasted images become block art; viewer windows get a marquee selection; right-click menus offer the commands.

**Architecture:** Pure logic in AnsiCore: `CellClipboard.swift` (the payload: region, iCE, font, nine pixel; cell bytes, plain text, ANSI text, PNG and TIFF data; which representations each copy kind writes; which pasteboard type a paste reads; viewer point to cell mapping; `AnsiScreen.region`; the column count for a pasted image) and `CanvasEditor` additions (floating paste: begin, move, stamp, cancel, transparent; region from text). The app adds `App/ArtPasteboard.swift` (writes a payload to an `NSPasteboard` as one item, reads cells, images and text back), editor changes in `App/AnsiEditor.swift` (floating paste display, keys and mouse, Copy As, image paste, context menu) and viewer selection in `Shared/AnsiPlayer.swift` (state, mouse, marquee layer; off unless the host turns it on, so Quick Look is unchanged) with its pasteboard actions in `App/ViewerCopy.swift`. `App/AnsiViewApp.swift` gains the Copy As submenu.

**Tech Stack:** Swift 5 mode, Swift Testing, AppKit, ImageIO, XcodeGen.

## Rulings

1. **Copy writes one pasteboard item** with, in order: `com.traynham.ansiview.cells` (the existing lossless `AVCELLS1` bytes), `public.utf8-plain-text` (UTF-8 text with CP437 mapped to Unicode, trailing spaces trimmed), `com.traynham.ansiview.ansi` (UTF-8 text with 24 bit SGR colours, `TextConvert.modernANSI(.trueColor)`, which terminals and AnsiView read back), `public.png` and `public.tiff` (LZW). Cells and text are written at once; the PNG and TIFF are promised through `NSPasteboardItemDataProvider` and drawn only when an app asks (review fix). Cost if wrong: an app that wants a different flavour order picks a different one.
2. **Copy As** writes one kind only: Text (plain text), ANSI (the escape text as the plain string, so any text field or `pbpaste > x.ans` gets the codes, plus the ANSI type), Image (PNG and TIFF). Select All is Cmd-A, the existing standard item.
3. **The picture** is the selected cells rendered with the art's font, nine pixel spacing, iCE (cells already hold the colours the bytes mean) at scale 2, blink shown, without the CRT effect or legacy aspect stretch. Expected size: `width * cellWidth * 2` by `height * fontHeight * 2`. When the renderer would have to lower the scale or drop rows (over 160 MB), the picture is rendered at the scale that fits and is left out entirely when not every row fits. Cost if wrong: a huge selection pastes without a picture.
4. **Paste reads** cells first; then AnsiView's ANSI type (parsed as art); then an image (PNG, TIFF, JPEG) when the pasteboard has no plain text; then plain text; then an image. Apps such as Word put a picture of copied text next to the text, so text wins over a picture; a screenshot or a copied web image has no text. Plain text that contains escape sequences (`ESC [`) is parsed as ANSI art too. Cost if wrong: a picture that comes with a caption string pastes as text (Copy As Image in the source app avoids it).
5. **Floating paste.** Paste (cells, text in the current colours, or a converted image) floats at the cursor, or at the clicked cell for a context menu paste. Arrows move it one cell (Shift: 8), dragging moves it, Return, Enter or a click without movement stamps it, Escape cancels. The canvas shows the result as it would be stamped. Stamping is one undo step named Paste, selects the pasted rectangle and moves the cursor to its top left. Cells beyond the right edge are dropped; rows grow up to 1500. While floating, other edits are not possible (typing T toggles transparency, everything else beeps). Starting another paste replaces the floating one. `CanvasEditor` refuses every other canvas change while a block floats and the menus disable them (review fix). Pasted cells are converted to the canvas's iCE setting the way Toggle iCE converts (review fix).
6. **Transparent paste:** a palette bar checkbox (and T while floating). Pasted cells whose character is space, NUL or 255 (any colour) leave the canvas cell underneath, as the owner asked ("spaces do not overwrite"). Cost if wrong: coloured spaces (background blocks) also do not paste when transparent.
7. **Image paste** converts with the last Import Image options (`ImageImportOptionsView.remembered`), with iCE forced to the canvas's own setting, at the selection's width when there is a selection, else the image's pixel width capped at the canvas width, at least 1. The result floats like any paste, at the selection's top left when there is a selection.
8. **Viewer selection.** `AnsiPlayerViewController.allowsSelection` (default false; set by the app's document windows, gallery slideshows and presentation mode; never by Quick Look). Dragging more than 3 points draws a marquee over the cells under it in the displayed frame (during tall art playback, the 25 row window on screen). A click without a drag clears a selection, or skips / replays as before when there is none. Escape clears (in presentation mode Escape still exits). Cmd-A selects the whole displayed screen. Copy and Copy As copy the displayed frame at the moment of copying (the current frame of an animation), with the same payload as the editor. A tall piece entering or leaving its playback window drops the selection (the same cells show other rows). Cost if wrong: an animated piece mid playback copies a frame the user did not expect; pausing first avoids it.
9. **Context menus.** Editor: Cut, Copy, Copy As (Text, ANSI, Image), Paste, Select All; opened by right-click in Select mode or Control-click in either mode (right-button drags keep painting the background colour in Draw mode, as before). Viewer (app only): Copy, Copy As, Select All. Items that cannot apply are disabled.
